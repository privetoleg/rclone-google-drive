Privacy Policy

Last updated: September 17, 2026

This Privacy Policy describes how the Personal Rclone Google Drive Integration accesses and uses Google user data.

Purpose

This application is a personal application used to connect rclone running on my personal devices to my Google Drive account for file synchronization, backup, and file management.

Google User Data

The application may access Google Drive files, folders, file metadata, and related information as authorized by the Google account owner through Google OAuth 2.0.

How Data Is Used

Google user data is used solely to perform file synchronization, backup, upload, download, listing, and file management operations requested by the account owner.

Data Storage

OAuth authorization credentials and tokens used by rclone are stored locally on devices controlled by the account owner.

This application does not operate a separate server or database for collecting Google user data.

Data Sharing

Google user data accessed through this application is not sold, rented, transferred, or shared with third parties for advertising, marketing, or other commercial purposes.

Data Retention

The application does not independently retain copies of Google Drive data beyond files intentionally transferred or synchronized by the account owner.

Revoking Access

Access can be revoked at any time through the security settings of the associated Google account.

Personal Use

This application is intended for personal use and is not offered as a public or commercial service.
