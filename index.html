Personal Rclone Google Drive Integration

This is a personal application used to connect rclone running on my personal devices to my Google Drive account.

The application is used for personal file synchronization, backup, and file management.

This application is not offered as a commercial service and is intended only for personal use.

Google Drive Access

The application uses Google OAuth 2.0 to authorize rclone to access my Google Drive account. Access is used only for synchronization and file management operations initiated by me.
